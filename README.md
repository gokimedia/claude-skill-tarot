# Deckaura Tarot Reading Skill

An open tarot-reading skill for Claude-compatible agent environments. It includes a structured starter workflow, spread references, symbolism notes, and Deckaura's complete 78-card dataset.

## Contents

- `tarot-reading/SKILL.md` — skill instructions and safety guidance
- `tarot-reading/resources/deck.json` — structured 78-card reference data
- `tarot-reading/resources/spreads.md` — common spread layouts
- `tarot-reading/resources/symbolism.md` — elemental and numerological references

## Install

Copy the `tarot-reading` directory into the skills directory supported by your agent, or package that directory as a ZIP for manual skill upload.
